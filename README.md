# Bubble

브라우저에서 바로 실행되는 퍼즐 보블 스타일 버블 슈터 게임입니다.
TypeScript로 작성했으며, 빌드 결과물은 외부 리소스 없이 동작하는 **단일 `index.html` 파일**(약 53 KB)입니다.
서버 없이 `file://`로 열어도 실행됩니다.

## 특징

- 200개 스테이지 (10개 월드 × 20스테이지, 각 월드 마지막은 보스 스테이지)
  - 1~10: 직접 설계한 스테이지
  - 11~200: 시드 기반 생성기로 만든 뒤 검증을 거쳐 `src/stages/stages.json`에 고정
- 월드가 올라갈수록 색 수(3→8색), 초기 행 수, 천장 하강 속도가 증가
- 벽 반사를 포함한 조준 가이드선
  - 스테이지 1은 항상 표시, 스테이지 2부터는 각 판의 첫 발에만 표시
  - 헬프를 쓰면 다음 1발 동안 가이드 표시 (월드와 관계없이 반사 경로까지)
- 모든 그래픽은 Canvas 2D로, 모든 효과음은 WebAudio로 코드에서 생성 (이미지·오디오 파일 없음)
- 진행도(해금 스테이지, 스테이지별 최고 점수, 음소거 설정, 헬프 횟수)를 `localStorage`에 저장
  - 저장소를 쓸 수 없는 환경에서는 메모리에만 보관하고 게임은 정상 진행
- 마우스·터치·키보드 지원, 창 크기에 맞춰 화면 비율 유지

## 플레이 방법

`release/index.html`을 브라우저로 엽니다. 빌드 방법은 아래 [빌드](#빌드)를 참고하세요.

### 규칙

- 같은 색 버블을 3개 이상 연결하면 터집니다.
- 터진 뒤 천장과 이어지지 않은 버블은 함께 떨어집니다.
- 일정 횟수를 쏠 때마다 천장이 한 줄 내려옵니다. 내려오기 직전에는 보드가 흔들리며 경고합니다.
- 버블이 바닥의 경계선에 닿으면 게임 오버, 보드를 모두 비우면 클리어입니다.

### 조작

| 동작 | 마우스 / 터치 | 키보드 |
|---|---|---|
| 조준 | 포인터 이동 | `←` `→` |
| 미세 조준(탭마다 5°) | 화면 좌·우 하단의 ◀ / ▶ 버튼 | — |
| 발사 | 클릭 / 탭 (해당 지점으로 조준 후 발사) | `Space` 또는 `↑` |
| 헬프(가이드 1발 표시) | 화면 하단의 `HELP n` 버튼 | `H` |
| 일시정지 | 화면 우측 하단의 일시정지 버튼 | `P` 또는 `Esc` |
| 소리 켜기/끄기 | 타이틀·스테이지 선택 화면 우측 상단의 `SND`/`OFF` 버튼 | `M` |
| 메뉴 선택 | 버튼 클릭 | 방향키 + `Enter` / `Space`, `Esc`로 뒤로 |

브라우저 탭을 벗어나면 게임이 자동으로 일시정지됩니다.

### 점수

| 항목 | 점수 |
|---|---|
| 터뜨린 버블 | 개당 10점 |
| 떨어뜨린 버블 | 10 × 2ⁿ점 (n = 떨어진 개수, 최대 16) |
| 클리어 보너스 | 1000 + max(0, 50 − 사용한 발수) × 20점 |

헬프를 켜고 쏜 발은 그 발에서 얻은 점수(터뜨림 + 떨어뜨림)만 0.1배(소수점 버림)로 받습니다. 클리어 보너스는 줄지 않습니다.

### 헬프

- 처음에 3회 주어지며, 최대 3회까지만 보유합니다.
- 스테이지를 3번 클리어할 때마다 1회 충전됩니다 (이미 깬 스테이지 재클리어도 포함).
- 가이드가 이미 보이는 상황(스테이지 1, 각 판의 첫 발)에서는 쓸 수 없습니다.
- 남은 횟수와 누적 클리어 수는 진행도와 함께 저장됩니다.

## 개발

### 요구 사항

- Node.js 22.12 이상 (Vitest 5 요구 사항)
- npm

### 명령어

```bash
npm ci                 # 의존성 설치
npm run dev            # 개발 서버 실행 (Vite)
npm test               # 테스트 실행 (Vitest)
npm run typecheck      # 타입 검사
npm run gen:stages     # 스테이지 11~200 재생성 → src/stages/stages.json
npm run build          # release/index.html 빌드
npm run verify:release # 릴리스 결과물 검증
```

### 빌드

macOS / Linux / Git Bash:

```bash
./build.sh
```

Windows (명령 프롬프트 또는 PowerShell):

```bat
build.bat
```

`build.bat`은 어느 폴더에서 실행해도 스크립트가 있는 폴더 기준으로 동작하며, 실패하면 `빌드 실패`를 출력하고 종료 코드 1을 반환합니다. 파일은 CP949 인코딩이므로 수정할 때 인코딩을 유지해야 한글 주석이 깨지지 않습니다.

두 스크립트 모두 다음 순서로 실행하며, 하나라도 실패하면 즉시 중단합니다.

1. `node_modules`가 없으면 `npm ci`
2. 타입 검사
3. 테스트
4. 빌드
5. 릴리스 검증

릴리스 검증(`scripts/verify-release.mjs`)은 다음 조건을 확인합니다.

- `release/`에 `index.html` 하나만 있는지
- 외부 `src`/`href` 참조와 원격 `url(...)`이 없는지
- 스크립트가 인라인으로 포함됐는지
- 파일 크기가 2 MB 미만인지

## 프로젝트 구조

```text
src/
  core/      게임 규칙 (DOM 비의존): 육각 그리드 보드, 매칭·낙하 판정, 발사 물리, 게임 상태 머신, 시드 난수
  stages/    스테이지 정의, 수제 스테이지, 패턴 기반 생성기, stages.json
  render/    Canvas 렌더러, 파티클·흔들림 효과
  input/     마우스·터치·키보드 입력
  audio/     WebAudio 합성 효과음
  storage/   진행도 저장
  ui/        타이틀·스테이지 선택·플레이 화면 전환
  main.ts    진입점 (고정 스텝 게임 루프)
scripts/     스테이지 생성, 릴리스 검증 스크립트
tests/       단위·통합 테스트
```

게임 규칙(`src/core`)은 DOM에 의존하지 않으므로 브라우저 없이도 테스트할 수 있습니다.
물리는 1/120초 고정 스텝으로 계산해 프레임레이트와 관계없이 같은 입력에는 같은 결과가 나옵니다.

## 기술 스택

- Vite 8 + vite-plugin-singlefile (단일 HTML 번들)
- Vitest 5
- 런타임 의존성 없음
